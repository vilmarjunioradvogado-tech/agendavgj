# 🤖 Super Funcionário Digital — Vilmar Junior Advocacia

Este repositório é o **funcionário digital** do escritório: um agente de IA
(Claude) configurado para produzir conteúdo, gerenciar agenda e e-mails,
redigir petições, executar tarefas e criar sites — tudo por conversa, sem
programação.

**👉 Comece lendo o [MANUAL-DO-CHEFE.md](MANUAL-DO-CHEFE.md)**

## Estrutura

| Pasta/arquivo | O que é |
|---|---|
| `CLAUDE.md` | O "cérebro": identidade, funções e limites do funcionário |
| `MANUAL-DO-CHEFE.md` | Guia de uso com exemplos de comandos |
| `base-de-conhecimento/` | Memória permanente do escritório |
| `.claude/skills/` | Habilidades: conteúdo, agenda, e-mails, sites |
| `site/` | Páginas e landing pages criadas (já tem uma pronta) |
| `producao/` | Entregas geradas: posts, fichas de clientes, relatórios |
