# Playbook: Pesquisa Jurídica

**Delegável?** PARCIALMENTE — estagiário executa, Vilmar valida estratégia

## O que envolve

Pesquisa de jurisprudência (STJ, STF, TJs), doutrina, legislação atualizada,
precedentes vinculantes.

## Fluxo delegado

1. **Vilmar define** a tese a pesquisar em uma frase (ex: "responsabilidade da operadora por negativa de cobertura de cirurgia bariátrica")
2. **Estagiário / MCP Jurisprudência** executa a pesquisa no DataJud, Jusbrasil, STJ.jus.br
3. **Entrega**: documento com 5–10 ementas relevantes + link + data da decisão
4. **Vilmar valida**: seleciona as 2–3 mais pertinentes para a peça

## Checklist de entrega (estagiário → Vilmar)

- [ ] Pelo menos 1 acórdão do STJ ou STF
- [ ] Acórdãos dos últimos 3 anos prioritariamente
- [ ] Ementa completa copiada (não resumida)
- [ ] Link direto para o acórdão acessível
- [ ] Sinalizar se é decisão unânime ou por maioria

## Ferramenta disponível

MCP Jurisprudência (já instalado no SISTEMA VGJ) — use-o antes de pesquisar manualmente.

## O que Vilmar não delega aqui

A decisão de qual linha argumentativa usar — isso é estratégia processual.
