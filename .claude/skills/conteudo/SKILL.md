# Criação de Conteúdo — Vilmar Junior Advocacia

## Antes de escrever

1. Leia `base-de-conhecimento/tom-de-voz.md` e `base-de-conhecimento/escritorio.md`
2. Confirme o formato se não estiver claro: post estático, carrossel, Reels ou artigo

## Regras de ouro (OAB — Provimento 205/2021)

- Conteúdo sempre **informativo e educativo**
- NUNCA prometer resultado ("garanta sua aposentadoria" ❌ → "entenda se você tem direito" ✅)
- NUNCA mencionar valores de honorários em publicidade
- NUNCA usar caso real de cliente identificável
- CTA permitido: convite para contato/dúvidas, nunca captação agressiva

## Formato de entrega

Para cada peça de conteúdo, entregar:

1. **Título/gancho** — primeira frase que prende atenção
2. **Texto completo** — pronto para copiar e colar
3. **Sugestão de arte** — descrição da imagem/slides para o designer ou Canva
4. **Legenda + hashtags** — 5 a 10 hashtags relevantes da área
5. Salvar tudo em `producao/conteudo/AAAA-MM-DD/` como arquivos .md

## Estruturas prontas

- **Post educativo:** Gancho (dúvida comum) → Explicação simples → Exemplo prático → CTA leve
- **Carrossel (7-10 slides):** Capa com promessa de aprendizado → 1 ideia por slide → penúltimo resume → último com CTA
- **Roteiro de Reels (30-60s):** Gancho em 3s → problema → virada/informação → CTA falado
