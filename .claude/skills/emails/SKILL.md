# E-mails — Vilmar Junior Advocacia

Use as ferramentas do Gmail (mcp__Gmail__*). Carregue-as com ToolSearch se
necessário.

## Regra de segurança absoluta

**NUNCA enviar e-mail.** Toda resposta é criada como RASCUNHO
(`create_draft`) para o Dr. Vilmar revisar e enviar manualmente.

## Triagem (quando pedirem "meus e-mails")

Classificar os não lidos em:

1. 🔴 **Urgente** — intimações, prazos, tribunais (PJe, e-SAJ, Projudi), clientes com problema
2. 🟡 **Importante** — clientes, propostas, contatos novos
3. ⚪ **Pode esperar** — newsletters, propaganda, avisos

Entregar resumo de 1 linha por e-mail, começando pelos urgentes.

## Rascunhos de resposta

- Tom conforme `base-de-conhecimento/tom-de-voz.md` (cordial, senhor/senhora)
- Sempre indicar próximos passos concretos e, se fizer sentido, sugerir horário
  de reunião consultando a agenda
- Nunca confirmar tese jurídica ou prazo sem certeza — deixar
  `[DR. VILMAR: confirmar este ponto]` no rascunho quando houver dúvida
