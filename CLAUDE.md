# Instruções para o Claude neste repositório

## Copywriting Engine — ativação automática

Este repositório contém a skill **copywriting** (`.claude/skills/copywriting/`), o Copywriting Engine do escritório VGJ LAW.

**Ative a skill `copywriting` sempre que o usuário:**

- Pedir qualquer texto de venda, anúncio, headline, página, landing page, carrossel, post, legenda, story, e-mail, sequência, roteiro de vídeo, VSL ou mensagem de WhatsApp;
- Usar os comandos `/auto`, `/copy`, `/oferta`, `/diagnostico`, `/critica`, `/ab`, `/pesquisa`, `/juridico`, `/saude` ou qualquer comando de formato (`/headline`, `/anuncio`, `/pagina`, `/email`, `/carrossel`, `/video`, `/whatsapp`);
- Pedir "copy", "texto persuasivo", "diagnóstico de oferta" ou algo equivalente — mesmo sem citar a skill pelo nome.

O usuário costuma conversar pelo celular, com mensagens curtas e informais. Na dúvida entre "é pedido de copy" ou não, pergunte de forma direta e simples.

## Contexto do escritório

- Usuário: Vilmar Guimarães Júnior, advogado (Brasil). Peças de publicidade devem respeitar as regras da OAB — os modos `/juridico` e `/saude` da skill tratam disso.
