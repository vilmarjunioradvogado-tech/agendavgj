# Templates de Qualificação — WhatsApp

## Fluxo de qualificação por área

Use essas perguntas para entender o caso antes de agendar consulta.

---

### TRABALHISTA

**Mensagem 1 — primeiro contato:**
```
Olá, [Nome]! Tudo bem?

Para eu entender melhor o que está acontecendo, me conta:

1️⃣ Você ainda está empregado ou já foi desligado?
2️⃣ Se foi demitido — foi com ou sem justa causa?
3️⃣ Há quanto tempo estava na empresa?
```

**Se tiver pendências:**
```
Você recebeu o acerto completo (FGTS, aviso prévio, 13º proporcional)?
Tem a CTPS e os contracheques dos últimos 6 meses?
```

---

### CONSUMIDOR

**Mensagem 1:**
```
Oi, [Nome]! Me conta um pouco mais:

1️⃣ O problema é com produto ou serviço?
2️⃣ Foi comprado há quanto tempo?
3️⃣ Já tentou resolver diretamente com a empresa?
```

**Se for plano de saúde:**
```
O plano negou qual procedimento?
Você tem o laudo médico recomendando?
A negativa foi por escrito?
```

---

### PREVIDENCIÁRIO

**Mensagem 1:**
```
Olá! Para entender seu caso:

1️⃣ O INSS negou qual benefício?
2️⃣ Você tem a carta de indeferimento?
3️⃣ Já fez algum recurso administrativo?
```

---

### FAMÍLIA

**Mensagem 1:**
```
Oi, [Nome]!

Para entender melhor a situação:

1️⃣ Vocês têm filhos menores?
2️⃣ A separação é de comum acordo ou há conflito?
3️⃣ Têm bens a partilhar (imóvel, carro, etc.)?
```

---

## Mensagem de transição para consulta

Após qualificar:
```
Obrigado pelas informações, [Nome].

Com base no que você me contou, é uma situação que vale a pena analisar com cuidado.

O próximo passo é uma consulta, onde eu examino tudo e te explico exatamente quais são as suas opções.

Você tem disponibilidade [dia] à [hora] ou [dia alternativo]?
```

## Mensagem quando não é caso para atuar

```
[Nome], obrigado por compartilhar sua situação.

Com base no que você me descreveu, [motivo pelo qual não é o caso mais indicado].

O que eu recomendo é [orientação alternativa — ex: Procon, Juizado Especial, etc.].

Se surgir algo na minha área, pode contar comigo.
```
