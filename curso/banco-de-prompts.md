# Banco de Prompts Jurídicos — material de apoio do curso

> **Como usar:** copie, substitua os campos entre `[colchetes]` e ajuste ao seu caso. Todos pressupõem dados **anonimizados** (Módulo 1, Aula 3). Acrescente sempre que precisar a *cláusula de segurança* abaixo.

**Cláusula de segurança (colar ao final dos prompts importantes):**
```
Não cite jurisprudência ou dispositivo legal sem alertar que preciso conferir na
fonte oficial. Se houver correntes divergentes, apresente as duas. Aponte
expressamente os pontos em que você tem incerteza. Não invente dados que
faltam — pergunte.
```

---

## 1 · Análise de casos

**1.1 Triagem de caso novo**
```
Você é um advogado [área] experiente. A seguir, o relato anonimizado de um
possível cliente: [colar relato].
Produza: (1) linha do tempo datada dos fatos; (2) questões jurídicas
identificadas; (3) documentos que devo solicitar ao cliente; (4) riscos e
prazos que exigem atenção imediata (prescrição, decadência); (5) perguntas
que ficaram sem resposta no relato.
```

**1.2 Teses de ambos os lados**
```
Com base no caso acima, liste as 5 melhores teses do AUTOR e, em seguida, as
5 melhores teses da defesa da RÉ. Para cada uma: fundamento central e
principal fragilidade. Ao final, diga qual lado está mais frágil e por quê.
```

**1.3 Viabilidade da demanda**
```
Avalie a viabilidade desta demanda em três cenários (conservador, realista,
otimista), indicando para cada um: probabilidade de êxito estimada, riscos de
sucumbência e o que precisaria ser provado. Deixe claro que é análise
preliminar para apoiar minha decisão, não substituí-la.
```

## 2 · Análise de autos e documentos

**2.1 Tabela pedido × defesa**
```
A partir da inicial e da contestação anexadas: monte uma tabela com colunas
PEDIDO · FUNDAMENTO DO AUTOR · RESPOSTA DA DEFESA · PROVA RELACIONADA ·
SITUAÇÃO (controvertido/incontroverso). Indique a página/ID de origem de cada
informação.
```

**2.2 Ficha de processo padronizada**
```
Preencha a ficha abaixo a partir dos autos anexados, indicando a página/ID de
origem de cada informação:
1. Fase atual  2. Objeto em uma frase  3. Pedidos e valores  4. Linha do
tempo (data · evento · fls.)  5. Quadro de provas (prova · quem produziu ·
o que demonstra)  6. Decisões proferidas  7. Pendências  8. Riscos.
```

**2.3 Contradições em depoimentos**
```
Compare os depoimentos anexados. Para cada depoente: (1) o que afirmou de
relevante; (2) em que pontos confirma os demais; (3) em que pontos contradiz
— citando os trechos literais entre aspas com a localização de cada um.
```

**2.4 Análise de contrato**
```
Analise o contrato anexado sob a perspectiva do [CONTRATANTE/CONTRATADO].
Liste: (1) cláusulas de risco e por quê; (2) cláusulas potencialmente nulas ou
abusivas; (3) omissões relevantes (o que deveria existir e não existe);
(4) sugestões de redação para renegociação. Cite o número de cada cláusula.
```

**2.5 Resumo de decisão/acórdão**
```
Resuma a decisão anexada: (1) resultado em uma frase; (2) fundamentos
centrais em tópicos; (3) tese firmada, se houver; (4) 3 trechos literais
citáveis (entre aspas, com localização); (5) desdobramentos práticos para a
parte [vencedora/vencida] — prazos e medidas cabíveis.
```

## 3 · Produção de peças

**3.1 Esqueleto de peça**
```
Decidi sustentar as teses: [listar]. Monte o roteiro de uma [peça] com a
estrutura de tópicos do modelo anexado, indicando para cada tópico: o que
será dito, em que ordem, e qual prova/documento o sustenta. Não redija ainda
— só o esqueleto para minha aprovação.
```

**3.2 Redação dos fatos**
```
Com base na linha do tempo aprovada, redija a seção "DOS FATOS" da peça:
narrativa clara, cronológica, sem adjetivação excessiva, preparando o terreno
para as teses [listar], no tom do modelo anexado.
```

**3.3 Redação de fundamento**
```
Redija o tópico "[título do fundamento]" sustentando que [tese]. Estruture:
premissa normativa → aplicação aos fatos → conclusão. Deixe marcadores
[JURISPRUDÊNCIA] nos pontos onde inserirei os julgados que eu mesmo
pesquisarei e conferirei.
```

**3.4 Contrarrazões ponto a ponto**
```
A parte contrária sustentou o seguinte: [colar argumento]. Produza a
refutação estruturada: (1) síntese honesta do argumento adverso; (2) por que
não se aplica ao caso; (3) argumentos subsidiários caso o principal não seja
acolhido.
```

**3.5 Pedidos**
```
A partir das teses e da narrativa aprovadas, redija a seção de pedidos:
completa, em ordem lógica, com pedidos subsidiários onde couber. Depois,
liste separadamente: (a) pedidos que podem ter ficado faltando;
(b) pedidos arriscados que merecem minha reavaliação.
```

## 4 · Revisão e qualidade

**4.1 Revisão de forma (sem tocar no mérito)**
```
Revise a peça anexada SEM alterar teses ou estratégia: gramática, clareza,
repetições, períodos longos demais e transições fracas. Aponte cada mudança
sugerida em lista (trecho original → sugestão → motivo) para eu aprovar
uma a uma.
```

**4.2 Revisão adversarial**
```
Você é o advogado da parte contrária. Ataque a peça anexada: aponte
fragilidades argumentativas, contradições internas, preliminares cabíveis e
os contra-argumentos que você usaria. Seja impiedoso — prefiro ouvir de você
do que do juiz.
```

**4.3 Teste de clareza judicial**
```
Você é um juiz com 80 processos na mesa e 10 minutos para esta peça. O que
ficou confuso? O que você pularia? Que informação essencial está difícil de
achar? Sugira o que cortar para reduzir a peça em 30% sem perder conteúdo.
```

**4.4 Varredura de anonimização**
```
Verifique se restou na peça algum destes marcadores de anonimização que
esqueci de substituir pelos dados reais: [colar termos da tabela de
substituição]. Liste cada ocorrência com a localização.
```

## 5 · Comunicação com o cliente

**5.1 Andamento em linguagem simples**
```
Explique a decisão anexada para o cliente leigo, em até 15 linhas:
(1) o que aconteceu; (2) o que significa na prática; (3) próximos passos e
prazos; (4) o que precisamos dele agora. Tom: tranquilizador e honesto, sem
juridiquês e sem promessas de resultado.
```

**5.2 Orientação pós-consulta**
```
Com base no atendimento resumido a seguir [colar], redija o e-mail de
follow-up ao cliente: síntese do que foi conversado, documentos que ele deve
enviar, próximos passos e prazo. Tom cordial e objetivo.
```

**5.3 Notificação extrajudicial em três tons**
```
Com os fatos a seguir [colar formulário preenchido], redija a notificação
extrajudicial em TRÊS versões: (a) conciliadora; (b) firme; (c) pré-
contenciosa anunciando as medidas cabíveis. Mesma estrutura nas três, para
eu escolher o tom.
```

## 6 · Estudo e atualização

**6.1 Mapa de um tema novo**
```
Preciso me atualizar sobre [tema]. Monte um mapa de estudo: (1) conceitos
essenciais; (2) marcos normativos aplicáveis; (3) controvérsias atuais;
(4) armadilhas para quem atua na prática; (5) o que devo pesquisar nas
fontes oficiais para confirmar, dado que seu conhecimento tem data de corte.
```

**6.2 Ficha de julgado (para tese em construção)**
```
Para cada julgado que eu colar a seguir, produza a ficha: tribunal · resultado
· ratio decidendi · trechos-chave · semelhanças com meu caso · distinções
relevantes. Lembre-me ao final de conferir cada julgado na fonte oficial
antes de citá-lo.
```

**6.3 Simulador de audiência**
```
Simule a audiência de instrução deste caso [colar ficha]: faça-me as
perguntas que o juiz provavelmente fará à minha testemunha e as que o
advogado adverso fará para desconstruí-la. Depois, aponte como preparar a
testemunha sem induzi-la.
```
